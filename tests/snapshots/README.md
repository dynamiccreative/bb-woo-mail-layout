# Snapshots HTML

Rendu final (CSS inliné par WooCommerce) de chaque e-mail détecté, dans les deux layouts.
Généré le 28/09/2026 sur WordPress 7.1.2 + WooCommerce 11.1.2 (locale en_US : les libellés propres à
WooCommerce — titres, sous-total, contenu additionnel — apparaissent en anglais ; ils sont en français sur un site FR).

Régénérer : `npm run snapshots` (wp-env).
